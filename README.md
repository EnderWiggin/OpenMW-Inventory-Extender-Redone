# Overview

Inventory Extender Redone is a rewrite of the UI of the Inventory Extender by Ralts - complete Lua replacement and overhaul of OpenMW's inventory window and other associated windows (barter, container, and companion share).

This UI rewrite uses UI Toolkit and has much better performance than the original Inventory Extender. It started as an exercise when preparing for the release of UI Toolkit and grown into a full-fledged rework. It is built on the tweaked version of Inventory Extender that I've been maintaining in Discord thread for some months in the absence of Ralts.
